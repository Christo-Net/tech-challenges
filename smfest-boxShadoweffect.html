Explanation: text-shadow: This CSS property adds shadows to the text. Multiple shadows are used to create the desired effect. The first shadow 0 0 10px rgba(0, 0, 0, 0.5) creates an outer glow effect. The values represent: 0: Horizontal offset (no offset). 0: Vertical offset (no offset). 10px: Blur radius (adjust for the size of the glow). rgba(0, 0, 0, 0.5): Color of the shadow (black with 50% opacity). The second shadow 0 0 20px rgba(0, 0, 0, 0.3) adds an inner glow effect, with a larger blur radius and lower opacity. background-color: Sets a dark blue background color similar to the image. color: Sets the text color to white. font-family, font-weight, font-size, letter-spacing: Adjusts the text appearance. display: flex, justify-content: center, align-items: center: Centers the text within the container. height: 100vh: Makes the container take up the full height of the viewport.
